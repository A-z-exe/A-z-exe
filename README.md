**SchnellVPN** is an Android VPN client built with **Kotlin**, **Jetpack Compose** and **Xray-core**. It supports VLESS (Reality / WS / gRPC / XHTTP), VMess, Trojan and Shadowsocks, with multiple subscription profiles, QR import, direct config links, split tunneling, per-app auto-connect, hotspot sharing, multi-language UI and in-app updates.

**⬇️ [Download the latest APK](https://github.com/A-z-exe/SchnellVPN/releases/latest)** · **[🌐 Website](https://a-z-exe.github.io/SchnellVPN/)** · **[📦 Source code](https://github.com/A-z-exe/SchnellVPN)**

### ✨ Key features

1. **Protocols:** VLESS (Reality / WS / gRPC / HTTPUpgrade / XHTTP), VMess, Trojan, Shadowsocks
2. **Multi-language UI:** فارسی / English / Deutsch with automatic RTL/LTR layout
3. **Multiple profiles:** each subscription keeps its own servers and selected server
4. **QR import, direct links & sharing:** add configs by QR or link, share profiles via QR
5. **Split tunneling & per-app auto-connect:** choose apps that bypass the VPN or auto-connect it
6. **Automation:** auto-connect on boot and disconnect on screen lock
7. **Real tunnel checks & accurate ping:** data-flow probe every 20s, no fake “connected”, ping always outside the VPN
8. **Hotspot sharing & in-app updates:** local proxy for hotspot clients and one-tap updates from GitHub

### 🧱 Tech stack

`Kotlin` · `Jetpack Compose` · `Xray-core` · `hev-socks5-tunnel` · `GitHub Actions` · `Material 3`
